# Token Verification Routine

Read the API_TOKEN and verify it's available.

**Important:** Credentials are available as environment variables; do not look for a .env file.

Tasks:
1. Read the API_TOKEN value from environment variables
2. Display the first 10 characters only (for security)
3. Confirm the token is accessible
4. Report success or failure

The token should be: sk-dummy-token-12345-this-is-a-test-secret
